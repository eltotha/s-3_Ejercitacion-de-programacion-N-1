# 📌 Proyecto

## ⚠️ En caso de que el servidor no corra

Sigue los siguientes pasos:

### 1. Inicializar el proyecto
Ejecuta el siguiente comando para crear el archivo `package.json`:

```bash
npm init -y
```

### 2. Descargar express en caso de no tenerlo
Ejecuta el siguente comando:

```bash
npm install express
```

### 3. ejecutar el server
Ejecuta el siguente comando:

```bash
node index.js
```
